# Presentation Guide

This document outlines how to structure your hackathon presentation.

Recommended presentation length:
3–5 minutes

---

# Slide Structure

Slide 1 — Title

Project name
Team name
Hackathon name

---

Slide 2 — Problem

What problem exists?
Who experiences it?
Why does it matter?

---

Slide 3 — Solution

Describe your solution clearly and simply

---

Slide 4 — Architecture

Explain system structure

Example:

Frontend → Backend → API → Database

---

Slide 5 — Demo

Show:

User interaction
Main feature
Output result

---

Slide 6 — Impact

Explain why your solution matters

Example:

Improves accessibility
Saves time
Reduces costs
Improves productivity

---

Slide 7 — Future Work

Explain next steps

Examples:

Scaling infrastructure
Adding new features
Mobile deployment

---

Slide 8 — Team

List team members and roles

Example:

Name — Role

---

# Presentation Tips

Keep explanations simple

Focus on the problem first

Show working prototype quickly

End with impact statement
