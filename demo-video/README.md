# Demo Video Script Guide

Recommended video length:

60–120 seconds

---

# Demo Structure

## Intro (10 seconds)

Introduce team and project

Example:

Hello, we are Team <Team Name> and this is our project <Project Name>.

---

# Problem (15 seconds)

Explain the problem clearly

Example:

Students spend too much time organizing notes manually.

---

# Solution (20 seconds)

Explain how your project solves the problem

Example:

Our application converts lecture notes into structured flashcards automatically using AI.

---

# Live Demo (45 seconds)

Show:

Input

Processing

Output

User interaction

Main feature

---

# Closing (10 seconds)

Example:

Thank you for watching our demo.

---
